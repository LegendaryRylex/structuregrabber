# Added

- `/structuregrabber`. Client-side command that takes two corners the way `/fill` does and writes the region between them to a structure `.snbt` file, linked in chat when it lands.
  - Corners can be set one at a time with `pos1`, `pos2`, `grab` and `clear`, instead of naming both in one go.
  - In single player the grab reads the hosted world, so block entities are complete and chunks outside render distance load on demand.
- Config for the output folder, whether entities and air are saved, and the largest region a grab may cover.
